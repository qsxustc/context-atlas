        CONTEXT ATLAS
        A map. A budget. A better prompt.
        1. Bring your code
          Open or drop a folder. Dependencies, generated files and common secret files are skipped. .gitignore rules are respected on a best-effort basis.
        2. Choose what matters
          Use Focus around one file, or choose Review a change and import a Git diff to gather changed files and their context. Review the connections, adjust the budget and rebuild before exporting.
        3. Check, then share
          Review the entire Markdown or XML export before pasting into your AI tool. Detected credential patterns are redacted by default.
        Files up to 1 MiB; projects up to 50 MiB of text. Token counts are approximate. Secret detection is heuristic and cannot catch everything. Source code and patches stay in memory and clear on closing. Saved recipes persist only paths, fingerprints and settings in this browser; JSON downloads include that metadata.
